# Типовые шаблоны кода (Patterns)

Готовые базовые шаблоны для типовых задач: вывод и ввод символов/строк, организация задержек, работа с курсором, рисование точек, цикл SOB, преобразование чисел в строку и синхронизация.

## Вывод строки на экран
```asm
        MOV #TEXT,R1
        CLR R2                  ; ограничитель = нулевой байт
        EMT 20
        ...
TEXT:   .BYTE 14                ; очистить экран
        .ASCII /Привет!/
        .BYTE 0                 ; конец строки
```

## Ввод символа и вывод
```asm
LOOP:   EMT 6                   ; ждём клавишу → R0
        EMT 16                  ; выводим
        BR LOOP
```

## Задержка (пустой цикл)
```asm
        MOV #DELAY_VAL,R0
WAIT:   SOB R0,WAIT
```

## SOB R2, . — пустой цикл задержки на месте

Самый короткий вариант задержки: одна инструкция, ветвится на себя:

```asm
        MOV  #N, R2
        SOB  R2, .          ; . = текущий адрес, крутится N раз
```

## Установка курсора в позицию X,Y
```asm
        MOV #X,R1
        MOV #Y,R2
        EMT 24
```

## Рисование точки
```asm
        MOV #1,R0               ; 1=нарисовать, 0=стереть
        MOV #X,R1
        MOV #Y,R2
        EMT 30
```

## Цикл SOB (N раз)
```asm
        MOV #N,R0
LOOP:   ; ... тело цикла ...
        SOB R0,LOOP
```

## Преобразование числа в десятичную строку (14 слов — оптимальный алгоритм)

Строка строится **справа налево** — нулевой терминатор пишется первым, цифры заполняются в обратном порядке. Стек для разворота цифр не нужен. После возврата **R1 указывает на первый символ** строки.

```asm
; Вход: R0 = число (0..65535), R1 = адрес ПОСЛЕ буфера (метка в конце)
; Выход: R1 → первая цифра нуль-терминированной строки
; Портит: R0, R1, R5
ITOA:   CLRB -(R1)              ; нулевой терминатор (в конце буфера)
1:      CLR R5
2:      INC R5
        SUB #10.,R0             ; вычитаем 10, пока R0 >= 0
        BHIS 2
        ADD #58.,R0             ; компенсация: +10 (откат) + 48 ('0' ASCII)
        MOVB R0,-(R1)           ; записываем цифру справа
        MOV R5,R0               ; R5 = частное+1 → R0
        SOB R0,1                ; SOB декрементирует: R0 = частное; ветвь если ≠ 0
        RET

        .BLKB 5
ITOA_END:                       ; передавать R1=#ITOA_END; буфер — 5 цифр + нуль = 6 байт
```

**Ключевые приёмы:**
- `CLR R5` вместо `MOV #-1,R5` — R5 выходит на 1 больше частного, SOB автоматически компенсирует
- `ADD #58.` = `+10` (откат лишнего вычитания) + `+48` (ASCII '0') — два действия одной командой
- Заполнение справа налево — не нужен стек для обращения порядка цифр
- `SOB R0,1` вместо `DEC R0 / BNE 1` — одно слово вместо двух (с учётом, что R0 = частное+1)

## TST (SP)+ — нелокальный выход из подпрограммы

Выбрасывает адрес возврата из стека, превращая `JMP` в возврат из вызывающей функции. Аналог исключения — прыжок к обработчику ошибки минуя нормальный путь возврата:

```asm
        CALL Foo
        ; ... нормальное продолжение ...

Foo:    ; ...
        BCC  1
            TST  (SP)+      ; выбросить свой адрес возврата
            MOV  #ErrMsg, R1
            JMP  Error      ; уйти в обработчик ошибки, не возвращаясь в Foo
1:      RET
```

## WAIT — ожидание прерывания (vsync-синхронизация)

Команда `WAIT` останавливает процессор до прихода любого прерывания. Используется для синхронизации с вертикальным гасящим импульсом (vsync):

```asm
        MOV  #VSYNC, @#100  ; установить обработчик прерывания таймера
        MOV  #10.*400, @#PALETTE  ; запустить таймер (код без цвета = старт)
        ...
LOOP:   ; отрисовка кадра
        WAIT                ; ждать vsync-прерывания
        BR   LOOP

VSYNC:  RTI                 ; просто выйти из прерывания
```

Вектор таймера/vsync — адрес 000100. `RTI` возвращает управление после `WAIT`.

## Синхронизация с дисплеем через таймер

Ожидание нужной фазы разворота: таймер перезапускается, цикл ждёт пока счётчик не снизится до порогового значения:

```asm
        MOV  #1, @#TIMER        ; остановить и сбросить таймер (177712)
        MOV  #TIMER-4, R4       ; R4 → регистр предустановки (177706)
        MOV  #Refresh, (R4)+    ; загрузить начальное значение; R4 → счётчик (177710)
        MOV  #20, @#TIMER       ; запустить таймер

        MOV  #2, R5
Loop:   CMP  (R4), R5           ; счётчик > 2?
        BGT  Loop               ; ждать, пока не досчитает до 2
```

`TIMER-4` = 177706 (предустановка), после `(R4)+` — R4 = 177710 (счётчик).
