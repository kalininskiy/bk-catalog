# Ассемблер PDPy11 — синтаксис и возможности (Syntax)

Используемый ассемблер: **PDPy11** (purplesyringa/PDPy11).

Специфика синтаксиса ассемблера PDPy11, псевдоинструкции PUSH/POP, числовые форматы, выражения, локальные метки, директивы распределения данных и управления компиляцией.

## PUSH / POP

PDPy11 поддерживает псевдоинструкции `PUSH` и `POP`:

```asm
PUSH R5      ; эквивалент MOV R5, -(SP)
POP  R5      ; эквивалент MOV (SP)+, R5
```

Работает для любого регистра (R0–R5, SP, PC). Старые ассемблеры для БК (pdp11asm и др.) **не понимают** PUSH/POP — там писать через MOV.

## Форматы чисел

| Запись | Система |
|--------|---------|
| `1234` | **Восьмеричная** (по умолчанию) |
| `1234.` | Десятичная (суффикс `.`) |
| `0b101010` | Двоичная |
| `0o1234` | Восьмеричная (явная) |
| `0x1234` | Шестнадцатеричная |

Директива `decimalnumbers ON` переключает умолчание на десятичную систему.

## Арифметические выражения

В режиме pdpy11 (умолчание) поддерживаются выражения со скобками:

```
A = (B + C / 2) * 2 + 7 * 3
```

Операторы (по возрастанию приоритета): `|` `^` `&` `<<` `>>` `+` `-` `*` `/` `%`

В режиме `.SYNTAX pdp11asm` — только `+ - * /`, выполняются слева направо без приоритета.

## Локальные метки

Числовые метки (`1:`, `2:` ...) **уникальны в пределах файла** и **видны только между соседними глобальными (именованными) метками**. **Суффиксы `f`/`b` не поддерживаются** — писать просто `BR 1`, не `BR 1f`.

Если между командой `BEQ 42` и меткой `42:` стоит именованная метка (`DMS_LEFT:` и т.п.), ассемблер не находит `42:` и выдаёт ошибку компиляции. Решение — переименовать целевую числовую метку в глобальную (`M42:`).

Поведение зависит от команды:

| Команда | Значение |
|---------|----------|
| `BR 1` | переход на метку `1:` |
| `BR 1 - 2` | адрес метки `1:` минус 2 байта |
| `BR (1)` | переход на **глобальный адрес** 1 (не метка!) |
| `BR (1:)` | переход на метку `1:` в выражении |
| `JMP 1` | переход на **глобальный адрес** 1 |
| `JMP (1:)` | переход на метку `1:` |

Вывод: в `BR` голое число = метка; в `JMP` голое число = абсолютный адрес.

## Адрес загрузки

Директивы `ORG`, `.LINK`, `.LA` устанавливают адрес компоновки. **По умолчанию — 1000**, поэтому `.= 01000` в начале программы писать **не нужно**.

## Директивы данных

| Директива | Действие |
|-----------|----------|
| `.BYTE n` / `.DB n` | записать байт |
| `.WORD n` / `.DW n` | записать слово (2 байта) |
| `.BLKB n` / `.DS n` | n нулевых байт |
| `.BLKW n` | n нулевых слов |
| `.ASCII /str/` | строка без терминатора |
| `.ASCIZ /str/` | строка + нулевой байт |
| `.EVEN` | выровнять PC на чётный адрес |
| `ALIGN n` | выровнять PC кратно n |

## Директивы управления компиляцией

| Директива | Действие |
|-----------|----------|
| `.END` / `END` | конец файла |
| `.INCLUDE /file/` | включить файл |
| `.ONCE` | включить файл не более одного раза (для библиотек) |
| `.REPEAT n { ... }` | повторить блок n раз |
| `.SYNTAX pdpy11` | режим pdpy11 (умолчание) |
| `.SYNTAX pdp11asm` | режим совместимости с pdp11asm |
| `decimalnumbers ON/OFF` | умолчание: десятичная / восьмеричная |
| `insert_file /file/` | включить файл как бинарные данные |

## .repeat — развёртка цикла директивой PDPy11

Директива `.repeat N { ... }` генерирует N копий блока инструкций на этапе компиляции:

```asm
        .repeat X/8.
        {
            MOV  (R1)+, (R2)+   ; скопировать слово, оба указателя вперёд
        }
```

Результат: X/8 инструкций MOV подряд — без накладных расходов SOB и без регистра-счётчика.

## Форматы выходного файла

| Директива в исходнике | Формат |
|-----------------------|--------|
| `make_bin` / `make_bk0010_rom` | `.bin` с заголовком (стандарт БК) |
| `make_raw` | без заголовка |
| `make_sav` | `.sav` |
| `make_turbo_wav` | WAV турбо-загрузки |
| `make_wav` | WAV стандартной загрузки |

Имя файла `~speaker` — воспроизвести WAV через динамики прямо при компиляции.

## Запуск компилятора

```
pdpy11 prog.mac              # → prog.bin
pdpy11 prog.mac --raw        # → prog (без заголовка)
pdpy11 prog.mac --sav        # → prog.sav
pdpy11 prog.mac -o out.bin   # явное имя выходного файла
pdpy11 prog.mac --link 2000  # адрес загрузки (если нет .LINK в файле)
pdpy11 prog.mac --lst        # генерировать листинг .lst
pdpy11 prog.mac --syntax pdp11asm  # режим совместимости
pdpy11 --project ./dir       # компилировать весь проект
```
